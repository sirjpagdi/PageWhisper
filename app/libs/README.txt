Put the sherpa-onnx Android AAR in this folder.

1. Open https://github.com/k2-fsa/sherpa-onnx/releases and take the latest release.
2. Download the file named like  sherpa-onnx-1.x.y.aar  (if a release has no AAR, see ../../README.md, section "No AAR?").
3. Copy it here. Any *.aar in this folder is picked up automatically.
